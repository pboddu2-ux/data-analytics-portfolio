# Pioneer Dining Operations and Meal Utilization Analysis

## Overview

This project analyzes group dining reservation data maintained through a dining reservation system and spreadsheet workflows. The analysis was created to understand reservation demand, meal utilization, group patterns, and payment-method usage.

## Project Objective

The objective was to clean reservation records and create a clear operational summary that could support dining preparation and planning.

## Work Completed

- Cleaned reservation dates, times, meal periods, blank rows, and numeric meal fields.
- Removed sensitive information from the portfolio version.
- Organized the data for analysis using summary tables.
- Compared planned meals with used meals and remaining meals.
- Identified high-volume reservation dates.
- Compared meal volume by group type and meal period.
- Summarized payment methods.
- Created charts and a dashboard for presentation.

## Key Findings

- Total meals allotted: **5,626**
- Total meals used: **4,243**
- Total meals remaining: **1,383**
- Lunch represented the largest meal volume in the dataset.
- The busiest reservation dates were identified using meal-allocation totals.
- The dashboard shows the difference between planned meal demand and actual meal usage.
